# GPR 第一个模块：错误依据与筛选方案

本轮完成的是现有冠军的机制诊断和研发方案，尚未训练或选定新的创新模块。首要候选明确为：**工况条件化的退化相似度模块**，即让 GPR 区分“充电条件不同”和“健康状态不同”。这是待验证的机制假设；“各数据集全面改善”是验收目标，当前没有这样的实验证据。

## 1. 本次新增证据

重新构建六个开发折的 GPR，使用各折已经选定的参数和原源训练样本，没有重新调参。55 个电芯的全部保存预测均与重算结果逐点相同，最大绝对差为 0。诊断仅访问既有 XJTU 开发数据。

| 现象 | 具体证据 | 研发含义 |
|---|---|---|
| 3C 的预测退回源均值 | 3,577 个查询循环的预测全部落在源均值 99.077% 的 ±0.1 个百分点内；与任何源样本的最大 RBF 相关值均低于 0.01 | 当前相似度难以将这一工况与已学习的健康信息联系起来 |
| 工况电流主导距离 | 3C 到最近源样本的总平方距离中，电流特征占 82.51%；源电流约 2–4 A，目标约 6 A | 均值、最小、最大、首末电流五个高度冗余的特征重复计入了电流差异 |
| 微小变化可能被放大 | 2C 中，电流标准差这个特征占总最近邻平方距离的 63.39%；其源样本标准差约为 1.55e-5 A | 需要检验近常量特征和冗余特征的影响；尚不能仅凭此判定这些变化全是噪声 |
| 晚期高估不全是远距离造成 | R2.5、RW 的低 SOH 样本仍与源样本相似，但存在明显正偏差 | 改进需要保留能区分退化程度的信息，单纯拉近两个域也不充分 |
| 不确定性不能直接当纠错开关 | 3C 中，逐电芯误差与 GP 标准差的 Spearman 相关系数中位数为 -0.319 | 先验证不确定性是否有用，不能预设“不确定性越大就往下修正” |

距离贡献定义：对每个查询循环，取源训练集内的 21 维标准化特征最近邻；将每一维的平方差按通道汇总，再对全部查询循环求和并计算占比。这是当前度量的行为诊断，不等于改变该通道就必然改善预测。

原分层结果的低 SOH 电芯宏 MAE：3C 10.62、R2.5 6.86、RW 6.95 个 SOH 百分点。本轮机制诊断 JSON 中的阶段 MAE 按循环汇总，聚合方式不同，不能替换主表数字。

## 2. 为什么调整此前的模块优先级

此前“多尺度表征 + 不确定性感知校准”是两个初步假设。本次将第一模块的优先级收敛到工况与退化的相似度建模。

现有输入探针中，16 点处理改善了 4/6 个工况，三尺度 HI 改善了 2/6 个工况；两者总体增益的配对区间都跨零。直接 support 曲线相减则在全部六工况变差。因此，现有证据没有支持直接把多尺度或参考相减定为 M1。

## 3. 候选 M1 怎样工作

对每个电芯，用最早 K=10 个循环建立早期参考。保留当前部分充电曲线的绝对特征，同时建立相对本电芯早期状态的变化特征。学习一个共享变换，使 GPR 比较时能利用充电条件、退化变化和绝对曲线信息，并避免重复的电流统计量支配距离。

机制的学习信号来自源训练电芯：把源电芯也构造为“最早十点参考、后续已标注样本估计”的任务。所有参与学习的源标签必须在共同预算中；目标电芯后期标签不参与拟合。不同数据集沿用同一个已冻结的计算规则；允许按相同规则从各自十点参考计算条件信息。

第一轮优先使用共同的 21 维 HI 及其早期参考，检验核度量本身。若后续引入原始曲线编码器，应同时增加相同曲线输入的普通深核学习对照，区分额外表征能力与所提机制的贡献。核实现必须对称且半正定，例如通过共享特征变换后使用合法核，不能随意定义非对称的样本配对权重。

这一步不同时加入第二个校准模块。若普通核修正已经足够，或候选 M1 不能超过这些修正，就继续保留为普通 GPR 改进结果，重新检查研发假设。

## 4. 首轮对照清单

| 对照 | 所回答的问题 |
|---|---|
| 原 GPR source-only | 与已经保存的开发冠军衔接 |
| 去除冗余/近常量特征的 GPR | 收益是否只来自普通特征处理；筛选规则仅由训练与内层验证确定 |
| ARD-RBF / Matérn GPR | 普通的特征权重与核选择是否已经解决问题 |
| 增加部分充电电量、按可靠早期容量归一化等常规 HI 的 GPR | 简单物理量和单位处理是否足够；只积分观测充电片段，不能使用完整未来容量 |
| 用相同十点标签进行标准后验更新的 GPR | 收益是否仅来自使用了冠军 source-only 未利用的目标标签 |
| 绝对特征与参考变化直接拼接的 GPR | 收益是否仅来自新增参考输入 |
| GPR + 候选 M1 | 条件化的退化相似度是否有超出上述强对照的收益 |

所有对照共享电芯划分、充电窗口、源标签预算、目标十点权限和验证纪律。搜索配置数及停止规则在运行前记录。核参数或常规特征优化属于加强基线，不能计为本文独创模块的收益。当前表格的基线冠军仍是开发起点；新的研发比较必须同时报告这些更直接的 GPR 对照。

## 5. 怎样把“每个数据集都改善”落到实验里

先建立 XJTU、MATR、Tongji 的相容开发任务，并在每个任务上得到 GPR 与上述普通改进的对应成绩。MATR 按电芯和批次、Tongji 按材料和温度子域保持分组；先审核相同部分充电输入和实测容量标签是否适用。六个 XJTU 工况不能冒充六个数据集。

HUST 按既定策略承担冻结后的跨数据集核验；SNL、CALCE、Oxford、NASA 用于外部与稀疏标定压力测试。此前已访问的历史结果必须披露，不能重新声称这些数据全部从未被看过。对尚未参与本轮选择的评估集，冻结模型后再评分；若依据该结果修改模型，该评估就成为开发反馈，需要另设确认数据或收缩独立泛化主张。

主筛选逐数据集、逐工况检查，不只看总平均。建议将平均 MAE 相对下降 10%–15% 作为研发目标（以当前 XJTU 为例约为 2.71–2.56 个百分点），这不是效果预测；加强 GPR 后还须重新计算相对其性能的独立收益。

- 要称“各数据集全面改善”，须在预先声明的全部相容评估任务中，逐数据集报告 MAE、RMSE、P95-AE，并实际观察各项下降。
- 同时检查低 SOH 阶段、最差工况和电芯改善比例，不能靠少数大幅改善掩盖其他数据集退步。
- 分清平均数下降与统计证据。使用电芯层面的配对重采样；随机模块配对运行多个种子，领先候选再做固定配置确认。循环不能冒充独立电芯。跨多个数据集的显著性主张需要相应处理多重比较。
- 任一数据集退步就记录为未达到“全部改善”，保留失败结果。输入或实测标签不相容的数据集要按数据条件提前说明，不得根据成绩排除。
- 外部评估完成后，只有实际支持的范围才能写入论文；“每套已评估数据改善”也不代表任意新电池必然改善。

## 6. 参考论文与新颖性边界

心路历程的第 4.6–4.7 节要求单模块有效、完整消融和同类替代对照。本轮先落实一个候选 M1，再决定是否需要 M2。

本地 M4.pdf 第 7 页明确说明阶段训练配置不同，M0–M4 是开发记录，不能视为严格因果消融；其模块步骤也并非在全部数据集上一律提升。矿石论文的注意力模块针对图像特征匹配，本项目可以参考“问题—模块—替代对照”的研究顺序，模块本身须适合 GPR 与电池输入。
