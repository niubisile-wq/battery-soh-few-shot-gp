# 后续候选：共享退化函数与来源电芯随机斜率

状态：待实现与检验，不是已成立模块；不得依据当前查询误差设置工况开关。

## 证据和假设边界

差分候选已完成9490行独立复算。XJTU主要失败来自R3/RW，Sim_satellite因原验证选gain=0而不变。差分与直接目标的完整父模型对照，在三个数据集三指标的工况bootstrap区间均包含0。这只能说明当前对照不足以证明差分目标有稳定优势，不证明两者等效，也不证明失败必然由电芯差异引起。

下一假设：来源电芯各自的退化响应差异可能被全部归入共享函数；去掉每个电芯的常数项仍不能去掉电芯特有斜率。需要显式学习共享与个体部分，而不是继续修改测试时融合强度。

## 最小可区分实验

保持既有预算内Haar168/PCA8潜在输入z、标签预算、来源划分、前10目标支持及两核族不变。来源模型为 y_c(z)=f(z)+b_cᵀz+a_c+ε；差分正交对比H消除a_c。来源随机斜率b_c独立，均值0、协方差ρI/d。于是观测协方差为

    C = H [ K_shared + ρ blockdiag(Z_c Z_cᵀ/d) + σ²I ] Hᵀ

同一来源电芯的随机效应相关，不能当独立噪声。目标预测只提取共享f部分，再以前10标签锚定；不得传入来源电芯ID之外的测试标签。初版不根据目标历史重估随机斜率，以隔离来源分解机制。可把ρ固定0作为严格退化对照，ρ>0由来源边际似然拟合；固定边界后不得因外层结果移动。

随机斜率标准化使用预算内全来源z的尺度，不根据目标整段重拟合。必须报告ρ的边界命中、优化失败、共享信号与随机项尺度，警惕所有有效信号被个体项吸收。此时即使来源似然改善，也不等于跨工况性能提升。

## 实现前后检查

- 随机项按电芯块构造，跨电芯为0，半正定；单电芯常数平移不影响差分目标。
- ρ=0时与已有DifferenceGP在相同核参数下预测一致。
- 数值梯度、直接矩阵求解、序列化重放及来源预算掩码检查。
- 比较学习随机项与ρ=0，两者使用相同表示、核族、锚定和验证强度集合。不得混合每个数据集的事后赢家。
- 来源拟合/原验证选择全部冻结，再评分完整16组；仍要求三数据集三指标独立和完整叠加改善，以及控制、配对区间和风险稳定性。

## 文献与贡献边界

共享/个体效应的分解是已有多任务GP研究思路，不作为基础算法创新宣称。相关原始论文：Ho Yoon、Jeong、Kim，Doubly Mixed-Effects Gaussian Process Regression，AISTATS 2022，https://proceedings.mlr.press/v151/ho-yoon22a.html 。本文设计是较简单的来源电芯随机线性效应，不是该论文完整方法的复现，也无该论文性能保证。

上述尚未注册为实际全折实验协议；实现数值检查后再固定ρ初值/边界与优化设置，任何选择都要在新候选查询评分之前记录。
